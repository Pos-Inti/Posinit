💻 Programación

La programación permite crear aplicaciones, páginas web, videojuegos y sistemas mediante instrucciones que una computadora puede interpretar.

Tecnologías de programación

Algunas de las tecnologías más utilizadas en desarrollo de software.

🌐

HTML

HTML define la estructura y contenido de una página web mediante etiquetas como títulos, párrafos, imágenes y enlaces.

🎨

CSS

CSS permite modificar colores, tamaños, posiciones, animaciones y la apariencia general de un sitio.

⚡

JavaScript

JavaScript permite agregar interactividad y modificar dinámicamente los elementos de una página.

🐍

Python

Python destaca por su sintaxis sencilla y se utiliza en automatización, desarrollo web, datos e inteligencia artificial.

#️⃣

C#

C# es un lenguaje desarrollado dentro del ecosistema .NET y también es ampliamente utilizado con Unity.

🗄️

SQL

SQL permite consultar y administrar información almacenada en bases de datos relacionales.

Ejemplo interactivo

JavaScript puede modificar el contenido de una página en tiempo real.

const mensaje = "¡Hola desde JavaScript!";
document.getElementById("resultado").innerHTML = mensaje;
