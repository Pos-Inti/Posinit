Acerca del proyecto

POSINIT fue desarrollado como parte de la actividad GPDS P1-A1 utilizando GitHub para trabajar de manera colaborativa mediante ramas, commits, Pull Requests y la integración de cambios en la rama principal.

🚀 Nuestro objetivo es aprender a utilizar Git y GitHub para colaborar correctamente en un mismo proyecto web.
